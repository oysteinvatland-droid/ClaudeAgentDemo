# Norwegian Energy Market Dashboard

> **Live demo:** Deploy to GitHub Pages from the `docs/` folder.

A clean, dark-themed dashboard showing Norwegian electricity prices, NOK/USD exchange rates, and hydroelectric reservoir levels — updated daily via GitHub Actions.

Built as a demonstration of **role-based AI agent development** using the [Claude Agent SDK](https://github.com/anthropics/claude-agent-sdk-python): a coordinator, developer, and test agent each contributed to this project with distinct responsibilities.

---

## What It Shows

| Metric | Source | Update Frequency |
|--------|--------|-----------------|
| ⚡ Electricity prices (NO1 zone) | [hvakosterstrommen.no](https://www.hvakosterstrommen.no/strompris-api) | Daily |
| 💱 NOK/USD exchange rate | [Norges Bank API](https://data.norges-bank.no) | Daily (trading days) |
| 💧 Reservoir filling % | [NVE Magasinstatistikk](https://biapi.nve.no/magasinstatistikk/api) | Weekly |

Each metric shows a current value with day/week-over-week change, a 30-day sparkline, and a full 12-month trend chart.

## GitHub Pages Setup

1. Fork or push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch** → `main` → `/docs`
4. The dashboard will be live at `https://yourusername.github.io/ClaudeAgentDemo/`

The `update-data.yml` workflow runs twice daily and commits fresh JSON files to `docs/data/`, which GitHub Pages serves directly to the browser.

## Running the Multi-Agent Orchestration

The `agents/orchestrate.py` script demonstrates three AI agents analyzing this project:

```bash
pip install -r requirements.txt

# macOS / Linux
export ANTHROPIC_API_KEY=sk-ant-...

# Windows PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-..."

python agents/orchestrate.py
```

This runs:
1. **Coordinator Agent** — reads the codebase and produces a structured project spec
2. **Developer Agent** — analyzes the implementation and documents key decisions
3. **Test Agent** — reviews the code for edge cases and production issues

All three agents' reasoning is written to `AGENTS.md`. See that file to understand how the agents "think" about the project.

### Agent Architecture

```
COORDINATOR
  System prompt: Tech lead persona
  Tools: Read, Glob, Grep (read-only)
  Output → task spec with API decisions
       ↓
DEVELOPER
  System prompt: Senior engineer persona
  Tools: Read, Glob, Grep (read-only)
  Input: Coordinator output + source files
  Output → technical implementation analysis
       ↓
TEST AGENT
  System prompt: QA engineer persona
  Tools: Read, Glob, Grep (read-only)
  Input: Developer output + source files
  Output → validation report with specific findings
```

Each agent receives the previous agent's output as context, simulating how a real team shares knowledge.

## Running Data Fetchers Locally

```bash
pip install -r requirements.txt

# Fetch all three sources
python scripts/fetch_all.py

# Or individual sources
python scripts/fetch_prices.py
python scripts/fetch_exchange.py
python scripts/fetch_reservoirs.py
```

Outputs are written to `docs/data/*.json`.

## Design

- **Dark theme** matching analytical dashboards — CSS variables for all colors
- **Outfit font** from Google Fonts
- **Chart.js 4** from CDN — no build step required
- **Responsive** — works on mobile and desktop
- **Resilient loading** — `Promise.allSettled()` so one failed API doesn't break the page

## Data Sources

| Source | API | Notes |
|--------|-----|-------|
| Electricity prices | `hvakosterstrommen.no/api/v1/prices/{year}/{mm-dd}_{zone}.json` | Free, no auth, hourly data |
| Exchange rates | `data.norges-bank.no/api/data/EXR/B.USD.NOK.SP` | SDMX-JSON format, official central bank data |
| Reservoir levels | `biapi.nve.no/magasinstatistikk/api/Magasinstatistikk` | Weekly aggregate, NVE government agency |

All APIs are free and require no authentication.
